🚀 Workflow Builder - Complete Architecture

📋 What is the Workflow Builder?

A visual, no-code automation engine where business admins can create sophisticated workflows using drag-and-drop. Think of it as the "integration brain" of your CRM - connecting triggers, conditions, and actions to automate your sales processes.

⚡ Real-time Automation

Workflows execute instantly when triggered (lead created, deal moved, etc.)

🔀 Smart Branching

Multiple conditional paths - different actions for different scenarios

📊 Full Audit Trail

Every execution logged - see exactly what happened and why

🎯 Multi-Tenant Ready

Each company has isolated workflows - complete data privacy

🔧 Available Node Types

Trigger Nodes (Start Points)

Lead Created New lead enters system
Lead Updated Lead properties change
Deal Moved Deal changes stage
Ticket Created New support ticket
Scheduled Time-based trigger
Manual Trigger Admin runs manually

Action Nodes (Do Something)

Assign to User Round-robin or specific
Send Email Use email templates
Send SMS Text message
Create Task For assigned user
Update Field Modify properties
Change Status Move to new stage
Create Deal From lead
Notify Team In-app notification

Condition Nodes (Decision Points)

Lead Score If score > X value
Lead Source Website, LinkedIn, etc
Field Comparison Any field = value
Custom Logic Complex conditions

Utility Nodes (Advanced)

Delay Wait X days/hours
Wait for Event Until email opened, etc
Branch/Merge Split & recombine flows

💼 Real-World Use Cases

Lead Routing

New lead created → Check score → Auto-assign to best available sales exec (round-robin or by territory)

Nurture Sequences

Lead created → Email day 1 → Wait 2 days → Email day 3 → If opened, assign to sales; if not, continue nurturing

Deal SLA

Deal moved to "Proposal" → Create task → If no activity for 5 days → Send reminder → If 10 days → Escalate to manager

Lead Scoring

Page visit +5pts → Email opened +3pts → Form filled +10pts → When score >50 → Auto-assign to sales

Alerts & Notifications

High-value lead created → Notify manager via email → Post to Slack → Create follow-up task

Cross-sell

Deal won → Create upsell opportunity → Assign to account manager → Send upgrade email

🏗️ System Architecture

Database Tables (New)
✓ Workflow - Store workflow definitions
✓ WorkflowNode - Individual workflow steps
✓ WorkflowEdge - Connections between nodes
✓ WorkflowExecution - Execution history
✓ WorkflowExecutionLog - Step-by-step logs
API Endpoints (New)
✓ POST /api/workflows - Create workflow
✓ GET /api/workflows - List workflows
✓ PUT /api/workflows/[id] - Update workflow
✓ POST /api/workflows/[id]/execute - Run workflow
✓ GET /api/workflows/[id]/logs - Execution history

How It Works

Trigger fires (lead created) ↓ Query Workflow table for enabled workflows with this trigger ↓ Load workflow graph (nodes + edges) ↓ Create WorkflowExecution record ↓ Start from first node ├─ If ACTION node → Execute action → Log result → Move to next ├─ If CONDITION node → Evaluate → Branch to YES or NO path ├─ If DELAY node → Create delayed task → Resume later └─ If ERROR → Log error → Stop or continue based on config ↓ Mark execution as completed ↓ Result stored in WorkflowExecutionLog

📊 Example: Lead Routing Workflow

1. TRIGGER: Lead Created ↓ 2. ACTION: Update field → Set status = "new_lead" ↓ 3. CONDITION: Is lead score > 50? ├─ YES PATH: │ ├→ ACTION: Assign to Sales Exec (round-robin) │ └→ ACTION: Send welcome email │ ├→ Was email opened in 24h? │ │ ├─ YES: Create "Follow-up call" task │ │ └─ NO: DELAY 2 days │ │ └→ ACTION: Send reminder email │ └→ End workflow │ └─ NO PATH: ├→ ACTION: Add to nurture sequence └→ DELAY: 5 days └→ ACTION: Send nurture email └→ Score now > 50? ├─ YES: Assign to sales └─ NO: Continue nurturing
